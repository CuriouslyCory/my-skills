# Plan: #24 Cloud-backed `ms fav` (account favorites, local merge)

## Goal
When authenticated, `ms fav add/remove/list` read/write the user's account favorites
via the `favorite` tRPC router (#23 api-client). When unauthenticated, the current
local `config.favoriteRepos` behavior is byte-for-byte unchanged. `find` and
`add --favorite` resolve favorites from the same source. First authenticated `fav`
use offers a one-time local->account merge.

## Auth detection & dispatch
New shared module `apps/cli/src/core/favorites.ts`:
- `resolveFavoritesContext()`: loads config + credentials, resolves serverUrl + token
  via #23 helpers. Returns `{ authed, config, credentials, serverUrl, client }`.
  `authed` is true when a token resolves (credentials file or `MY_SKILLS_TOKEN`).
  `client` (typed tRPC, type-only AppRouter) is built only when authed.
- `fetchAllAccountFavorites(client)`: walks paginated `favorite.list` (pageSize 100)
  and returns every row.
- `resolveFavoriteRepoUrls(ctx?)`: the single source of truth for `find` /
  `add --favorite`. Authed -> account favorites filtered to `type === "repo"` mapped
  to `repoUrl`. Unauthed -> `config.favoriteRepos`. Throws on network/auth failure
  while authed (no silent divergence).
- `addRepoFavorite(githubSource, config)`: shared writer for `add --favorite`.
  Authed -> `favorite.add` (idempotent via `isFavorited` check). Unauthed -> exact
  existing local push + `saveConfig` (byte-for-byte).
- Merge marker helpers `hasMergedFavorites(serverUrl)` / `markFavoritesMerged(serverUrl)`
  persisted to `~/.my-skills/favorites-merge.json` as `{ mergedServers: string[] }`,
  keyed per serverUrl so a new server re-offers.
- Small pure helpers `repoUrlFromOwnerRepo`, `ownerRepoFromUrl`.

`apps/cli/src/commands/favorite.ts` rewrite: each subcommand resolves context; if
not authed it runs the ORIGINAL local logic verbatim (byte-for-byte). If authed it
runs `maybeMergeLocalFavorites` then the cloud op inside a try/catch that renders the
#23 `friendlyApiErrorMessage` on offline/unauth and sets exitCode 1.

## One-time merge
`maybeMergeLocalFavorites(context, skipPrompt)` (authed only):
- returns early if `hasMergedFavorites(serverUrl)`.
- if no local favorites: mark merged, no prompt.
- if `--yes` (`skipPrompt`): mark merged, skip the offer (no silent import).
- else prompt via `@inquirer/confirm` (default yes); on accept, `favorite.add` each
  local repo; then mark merged. Network failure during merge propagates to the outer
  catch and is NOT marked (so it can retry).
`-y, --yes` option added to the three `fav` subcommands.

## Richer cloud list
Authed `fav list` prints `name`, `type`, and `addedAt` per row plus the server URL
footer, versus the plain `owner/repo` local list.

## find / add --favorite share the source
- `find.ts`: action resolves `resolveFavoriteRepoUrls(ctx)`; on authed-offline prints
  the friendly error and returns. `buildSearchIndex(favoriteRepos)` now takes the
  resolved URLs instead of reading `config.favoriteRepos`. Only localized edits.
- `add.ts`: the `--favorite` block calls `addRepoFavorite(githubSource, config)`.
  One import + one block swap; no other add logic touched (clean #25 merge).
