# Plan #29: Publish library as agentskills.io-compatible repo + `ms publish`

Build on #25 (library + rendering), #28 (GitHub connector), #22/#23 (tokens + api-client),
#21/#26 (per-user scoping + hosted persistence). Publishing runs SERVER-SIDE via the #28
authenticated octokit and octokit's Git Data API (no local filesystem, so it works on Vercel).

## 1. Artifact -> directory rendering (discoverSkills-compatible)

Each selected artifact renders to a repo path `"<name>/SKILL.md"` (a directory per skill at
repo root). `discoverSkills` (`apps/cli/src/services/cache.ts`) walks the repo recursively and
picks up any `SKILL.md`, so a root-level `<name>/SKILL.md` is discovered and installable via the
existing `ms add owner/repo` with no auth.

`SKILL.md` content is produced with `buildSkillContent(frontmatter, body)` mirroring the CLI's
own `materializeCloudArtifact` (cloud-source.ts) so a published repo is byte-identical to what the
CLI would materialize locally:

```
frontmatter = { name, description, author?, version? }
body        = artifact.content
```

`parseSkillFrontmatter` validates `{ name, description }` (the fields discoverSkills reads) and
round-trips the body losslessly. Rendering lives in `packages/api/src/lib/publish.ts`
(`renderArtifactSkill`), a pure function.

## 2. Git Data API commit flow (server-side, no FS)

In `packages/api/src/lib/publish.ts` `publishTree(octokit, { owner, repo, private, files, message })`:

1. `repos.get({owner, repo})` -> if 404 `repos.createForAuthenticatedUser({name, private, auto_init:true})`.
   `auto_init` guarantees a base branch + initial commit so a ref exists.
2. Read default branch from the repo, `git.getRef({ref:"heads/<branch>"})` -> base commit sha.
3. For each file: `git.createBlob({content, encoding:"utf-8"})` -> blob sha.
4. `git.createTree({tree:[{path,mode:"100644",type:"blob",sha}]})` with NO `base_tree`, so the
   tree is the full desired repo content (de-selected artifacts are dropped cleanly).
5. `git.createCommit({message, tree, parents:[baseCommitSha]})` -> commit sha.
6. `git.updateRef({ref:"heads/<branch>", sha:commitSha})`.

Return `{ committed:true, commitSha, branch, htmlUrl }`.

## 3. Idempotency (no commit when unchanged)

"Unchanged" is detected in our own DB, not by reading the remote tree:
- Compute `hash = sha256(renderedSkillContent)` per selected artifact (node:crypto, as token-auth does).
- Persist the last-published map `{ [name]: hash }` (`artifactState`) plus `lastCommitSha`.
- On `run`, build the desired `{name: hash}` map and diff against `artifactState`:
  - `changed = (set of names differs) OR (any hash differs)`.
  - If `!changed` AND we have a `lastCommitSha` -> return `{ committed:false }`, NO octokit writes.
  - Else run `publishTree` with a summary message `Publish N skills (+A ~U -R)` from the diff.
Pure helpers: `hashContent`, `diffPublish`, `buildCommitMessage` (all unit-tested).

## 4. Persistence — new table `publish_targets` (both dialects + pg migration 0004)

One target per user (userId unique). Reuses nothing existing cleanly (config is generic KV; this
is structured state incl. per-artifact hashes), so a small dedicated table is justified.

Columns (sqlite `schema.sqlite.ts` + pg `schema.pg.ts`, snake_case cols, userId FK cascade):
`id, user_id, repo_name, repo_owner(null), visibility('public'|'private' default 'public'),
selection(JSON string[] default '[]'), last_commit_sha(null), last_published_at(null),
artifact_state(JSON default '{}'), created_at, updated_at`, `unique(user_id)`.

pg migration `packages/db/drizzle/pg/0004_*.sql` + `_journal.json` entry. sqlite via `db:push`.
Add the table to `packages/api/src/test-utils.ts` raw schema too.

## 5. `publish` tRPC router (`packages/api/src/router/publish.ts`, mounted in root.ts)

- `configure({ repoName, visibility, selection })` — upsert the user's `publish_targets` row.
- `status()` — returns `{ configured, repoName, repoOwner, visibility, selection, lastPublishedAt,
  lastCommitSha, url, artifacts:[{name, category, included, state}] }` where state is
  `published|pending|changed|removed` computed from current library hashes vs `artifactState`.
- `run()` — resolve octokit (#28), render + diff, publish-if-changed, persist, return
  `{ committed, url, commitSha, unchanged, summary }`. Maps `GithubConnectorError`
  (not_connected/missing_scope -> FORBIDDEN, token_revoked -> UNAUTHORIZED), matching github router.

All `protectedProcedure`, userId-scoped (#21).

## 7. `ms publish` CLI command (thin wrapper)

`apps/cli/src/commands/publish.ts` + register in program.ts. Loads config/credentials, resolves
token (AuthRequiredError -> clear login message, exit 1), `client.publish.run.mutate()`, prints
the result URL (or "already up to date"). Connector/auth errors rendered via
`friendlyApiErrorMessage`. Type-only AppRouter (no server runtime in bundle).
