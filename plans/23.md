# Plan: CLI API client + `ms login` / `logout` / `whoami` (#23)

Give the CLI an authenticated, typed HTTP client against the hosted tRPC API and a
browser-based login flow. Credentials live in `~/.my-skills/credentials.json`
(mode 0600), never in `config.json`. A web `/cli-auth` screen mints a personal
access token (#22) after explicit user confirmation.

Builds on: #20 better-auth (web session), #21 per-user scoping, #22 personal
access tokens (`token` router + Bearer context), #26 DEPLOY_MODE.

## Central risk: the CLI bundle must not pull server runtime

`AppRouter` is imported TYPE-ONLY (`import type { AppRouter } from "@curiouslycory/api"`).
`import type` is erased by esbuild, so no value require of `@curiouslycory/api`
(and therefore no better-sqlite3 / drizzle-orm / octokit) reaches the bundle.
`@curiouslycory/api` is added as a CLI devDependency only, and is left EXTERNAL
(not in tsup `noExternal`). Proof: measure `dist/bin/my-skills.js` size before
(546747 bytes) and after, and assert the bundle contains no `better-sqlite3` /
`drizzle-orm` / `octokit` / `@curiouslycory/api` runtime.

## 1. `serverUrl` config field (shared-types + CLI)

- Add `serverUrl: z.string().url().default("https://my-skills.dev")` to
  `ConfigSchema` in `packages/shared-types/src/index.ts`. Default is the hosted
  domain placeholder (overridable); recorded as a decision/risk for #27.
- Add `serverUrl` to `DEFAULT_CONFIG` in `apps/cli/src/core/config.ts` and apply
  the `MY_SKILLS_SERVER_URL` env override in `loadConfig` (mirrors the existing
  `MY_SKILLS_CACHE_DIR` / `MY_SKILLS_SKILLS_DIR` overrides). `config get/set/list`
  pick it up automatically (keys derive from `ConfigSchema.shape`).

## 2. Credentials module (`apps/cli/src/core/credentials.ts`)

- Path `~/.my-skills/credentials.json`. Shape (local zod schema):
  `{ serverUrl: string; token: string; username: string }`.
- `loadCredentials()` -> `Credentials | null` (null on missing/invalid).
- `saveCredentials(creds)` -> mkdir dir, atomic temp-write + rename, then
  `chmod 0600` the final file (temp written with `{ mode: 0o600 }`, chmod after to
  defeat umask). NEVER touches `config.json`.
- `deleteCredentials()` -> unlink, ignore ENOENT.
- Export `CREDENTIALS_PATH`.

## 3. API client module (`apps/cli/src/core/api-client.ts`)

- `import type { AppRouter }` only. `createTRPCClient<AppRouter>` with
  `httpBatchLink({ transformer: SuperJSON, url: serverUrl + "/api/trpc", headers })`.
  Transformer MUST be superjson to match the server (`packages/api/src/trpc.ts`).
- `@trpc/client` (catalog) + `superjson` (2.2.3, matches api) added to CLI deps.
- `resolveServerUrl({ config, credentials })`: `MY_SKILLS_SERVER_URL` env >
  `credentials.serverUrl` > `config.serverUrl`. (Env wins for CI; a minted token
  belongs to the server it was minted against, so credentials beats config default.)
- `resolveToken(credentials)`: `MY_SKILLS_TOKEN` env > `credentials.token`.
- `createApiClient({ serverUrl, token })` -> typed client, Bearer header when token.
- Error taxonomy helpers:
  - `AuthRequiredError` (thrown when no token) -> "Not logged in. Run `ms login`."
  - `classifyApiError(err)` -> `"unauthorized" | "offline" | "unknown"`
    (401 / `UNAUTHORIZED` -> unauthorized; fetch/ECONNREFUSED/ENOTFOUND -> offline).
  - `friendlyApiErrorMessage(err, serverUrl)` -> user-facing string.

## 4. `ms login` (`apps/cli/src/commands/login.ts`)

Browser + loopback callback (default), `--no-browser` paste fallback.

- Resolve `serverUrl` (env > config; no creds yet), `hostname = os.hostname()`,
  `state = randomBytes(16).hex` (CSRF nonce).
- Start a loopback HTTP server on `127.0.0.1:0` (ephemeral port). Testable helper
  `startCallbackServer({ state, timeoutMs })` -> `{ port, result: Promise, close }`.
  The server handles `GET /?token=&username=&state=` (or `?error=`), verifies the
  returned `state`, responds with a small HTML "you can close this tab" page, then
  resolves/rejects.
- Authorize URL:
  `${serverUrl}/cli-auth?callback=${enc("http://127.0.0.1:"+port)}&name=${enc(hostname)}&state=${state}`.
- Default: open the browser (`openBrowser` util: `open`/`xdg-open`/`start` via
  `child_process`, no new dep). `--no-browser`: print the URL and `@inquirer/input`
  prompt to paste the token; then resolve username via `auth.getSession`.
- On success: `saveCredentials({ serverUrl, token, username })`; print confirmation
  + token prefix. Timeout (default 300s) -> friendly failure.

## 5. `ms whoami` (`apps/cli/src/commands/whoami.ts`)

- Resolve token (env > creds) + serverUrl. No token -> print "Not logged in" and
  `process.exitCode = 1`.
- `client.auth.getSession.query()`; null -> revoked/expired message, exit 1.
- Else print `username (email)` + token prefix (`token.slice(0,8)`), exit 0.
- Offline -> friendly "server unreachable" message, exit 1.

## 6. `ms logout` (`apps/cli/src/commands/logout.ts`)

- No creds -> "Not logged in", exit 0.
- Best-effort revoke: `client.token.list`, find the single entry whose
  `tokenPrefix` matches `creds.token.slice(0,8)`, `token.revoke({ id })`. Any error
  (offline / already revoked) is swallowed (best-effort).
- `deleteCredentials()`; print "Logged out".

## 7. Register commands

`login`, `whoami`, `logout` in `apps/cli/src/program.ts`.

## 8. Web `/cli-auth` (`apps/web/src/app/cli-auth/`)

- `page.tsx` (server): read `callback`, `name`, `state` searchParams. Validate
  `callback` is loopback (`http://127.0.0.1:*` or `http://localhost:*`) via
  `isLoopbackCallback` -> otherwise render an error (blocks token exfiltration).
  `getSession()`; multi-user + no session -> `redirect('/login?redirect=' + enc(url))`.
  Else render `<CliAuthConfirm callback name state username />`.
- `cli-auth-confirm.tsx` (client): "Authorize CLI on `<name>`?" + token name.
  Authorize -> `trpc.token.create.mutate({ name })` -> redirect browser to
  `${callback}?token=&username=&state=`. Cancel -> `${callback}?error=access_denied&state=`.
- Login redirect support: `login/page.tsx` + `login-form.tsx` accept a relative
  `redirect` param (guarded to start with `/`) and route there post sign-in
  (also as GitHub `callbackURL`). Minimal, closes the return-to-cli-auth loop.

## Notes for #24 (cloud `ms fav`) and #25 (`@me/<name>`)

Both import `createApiClient` + `resolveServerUrl`/`resolveToken`/`loadCredentials`
and reuse `classifyApiError`/`friendlyApiErrorMessage` for the offline/unauth
messaging. The client is a plain typed tRPC proxy, so `favorite.*` and a future
`library.*` router are callable with no extra wiring.
